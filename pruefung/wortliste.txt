# pruefung/wortliste.txt - Wortliste fuer die Textpruefung (test_texte.py)
#
# Zweck: Die Lerninhalte (inhalte/*.json, inhalte/spiel/*.json) und die
# sichtbaren Texte der Programme sollen einheitlich und fehlerfrei bleiben.
# test_texte.py liest diese Datei und prueft damit alle Texte:
#
#   [verboten]  Schreibweisen, die nicht (mehr) vorkommen duerfen.
#               Format:  falsch -> richtig
#               Eine einfache Form gilt als ganzes Wort (keine Buchstaben
#               direkt davor oder dahinter). Zeilen mit "re:" am Anfang sind
#               regulaere Ausdruecke (Python re), z.B. fuer "als erstes",
#               das nur ohne folgendes Substantiv falsch ist.
#   [ausnahmen] Stellen, an denen eine verbotene Form richtig ist, weil sie
#               Code, eine Befehls- oder Programmausgabe, ein Eigenname,
#               ein Zitat oder ein Spiel-Schluessel ist.
#               Format:  verbotene Form | genauer Textausschnitt
#               Der Textausschnitt wird vor der Pruefung entfernt.
#   [bekannt]   Woerter, die hunspell (de_DE) nicht kennt, die aber richtig
#               sind: IT-Fachbegriffe, Abkuerzungen, Befehle, Produkt- und
#               Spielnamen. Die Rechtschreibpruefung laeuft nur, wenn
#               hunspell mit de_DE installiert ist (sonst wird sie
#               uebersprungen). Erzeugt aus der Woerterliste der Sichtung
#               0.53 (woerter.tsv), nur gesichtete, korrekte Woerter.
#               Ein Wort pro Zeile, Gross-/Kleinschreibung zaehlt.
#
# Neue Fachbegriffe: ins Feld [bekannt] eintragen. Neue Regel: ins Feld
# [verboten] eintragen und mit "python -m unittest test_texte" pruefen.
# Leerzeilen und alles hinter "#" werden ignoriert (in [verboten] und
# [ausnahmen] nur am Zeilenanfang, damit "#" in Mustern moeglich bleibt).
