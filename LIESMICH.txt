WAS IST DAS?
---------------------------------------------------------------------------
Ein Lernprogramm mit dunkler, moderner Dashboard-Oberflaeche (abgerundete
Kacheln, Farbverlaeufe):

  Dashboard          Alle Kennzahlen auf einen Blick: Gesamtfortschritt,
                     gelernte Karteikarten, beantwortete Quizfragen,
                     bearbeitete AP1-/AP2-Szenarien, Erfolgsquote,
                     Lernverlauf der letzten 14 Tage, Materialabdeckung,
                     Aktivitaet je Fachbereich, Lernkalender und der
                     Fortschritt je AP1- und AP2-Pruefungsthema.

  Karteikarten       67 Karten in drei Lernmodi: Freitext, Multiple Choice
                     und Aufdecken. Filterbar nach Fachbereich.

  Pruefungstrainer   150 Fragen, Test-Sessions mit frei waehlbarer Laenge,
                     Zeitmessung, Erklaerung zu jeder Antwort und
                     Bewertung nach IHK-Notenschluessel.

  AP1 Szenarien      10 Grundlagenaufgaben (1./2. Lehrjahr) mit eigenem,
                     automatisch mitwachsendem Loesungsfeld zum
                     schriftlichen Bearbeiten und anschliessender
                     Musterloesung.

  AP2 Szenarien      16 praxisnahe Pruefungsaufgaben, ebenfalls mit eigenem
                     Loesungsfeld und Musterloesung.

  Test Projekt       6 vollstaendige Projekt-Szenarien zum Ueben der
                     IHK-Projektarbeit (Ausgangssituation, Auftrag,
                     Rahmenbedingungen, Aufgaben und Loesungshinweise).

  Praxis-Rechner     Subnetting (IPv4 und IPv6), RAID-Kapazitaet (Netto,
                     Paritaet, Effizienz, Ausfalltoleranz) und
                     Bildschirm-Datenvolumen (Datenmenge und Datenrate),
                     jeweils mit aufklappbarem Rechenweg.

  Lernfortschritt    Historie aller Test-Sessions mit Diagramm.

Die vier Fachbereiche sind Netzwerk & Protokolle, IT-Sicherheit &
Datenschutz, Systeme/RAID & Hardware sowie Wirtschaft & Prozesse.


INSTALLATION (EMPFOHLEN) - FERTIGE INSTALLER
---------------------------------------------------------------------------
Fuer Windows, Linux und macOS gibt es fertige Installer. Sie bringen alles
mit, was das Programm braucht - Python oder weitere Software muss NICHT
installiert werden. Eine Internetverbindung ist nur zum Herunterladen
noetig.

Die Installer stehen auf der GitHub-Seite des Projekts unter "Releases".
Die genaue Anleitung fuer jedes Betriebssystem steht in der Datei
INSTALLER-ANLEITUNG.txt. Kurzfassung:

  Windows :  FISI-Lernplattform-Setup-<Version>.exe starten und dem
             Assistenten folgen. Keine Admin-Rechte noetig.

  Linux   :  Debian/Ubuntu/Mint: das .deb-Paket installieren mit
               sudo apt install ./fisi-lernplattform_<Version>_amd64.deb
             Alle anderen: die .AppImage-Datei ausfuehrbar machen
             (chmod +x) und per Doppelklick starten.

  macOS   :  Die .dmg-Datei oeffnen und "FISI-Lernplattform" in den
             Ordner "Programme" ziehen. Fuer Apple-Chips (M1 und neuer)
             die Datei mit "arm64" im Namen nehmen, fuer aeltere Macs die
             mit "intel". Beim ersten Start Rechtsklick -> "Oeffnen"
             waehlen (siehe INSTALLER-ANLEITUNG.txt).


START AUS DEM QUELLCODE (fuer Entwickler)
---------------------------------------------------------------------------
Wer am Programm selbst arbeiten moechte, startet es direkt aus den
.py-Dateien. Dafuer werden benoetigt:

  * Python 3.8 oder neuer mit Tkinter
  * CustomTkinter und Pillow (einmalig installieren, siehe unten)

Einmalig im Programmordner ausfuehren:
  Windows :  python -m pip install -r requirements.txt
  Linux   :  python3 -m pip install --user -r requirements.txt
  macOS   :  python3 -m pip install -r requirements.txt

Danach starten mit:
  Windows :  python start.py
  Linux   :  python3 start.py
  macOS   :  python3 start.py

Tkinter unter Linux nachinstallieren, falls es fehlt:
  Debian/Ubuntu : sudo apt install python3-tk
  Fedora        : sudo dnf install python3-tkinter
  Arch          : sudo pacman -S tk

Python selbst gibt es unter https://www.python.org/downloads/ (unter
Windows bei der Installation "Add python.exe to PATH" ankreuzen).

Windows-Komfortstart per Doppelklick:
  Die Datei "FISI-Lernplattform starten.vbs" startet das Programm direkt
  aus dem Quellcode, ohne Konsolenfenster.

  Desktop-Verknuepfung mit eigenem Icon anlegen (einmalig):
    Doppelklick auf "Desktop-Verknuepfung anlegen.vbs".
  Diese Verknuepfung zeigt immer den aktuellen Stand der Programmdateien
  in diesem Ordner.

Linux-Startmenue-Eintrag fuer den Quellcode-Start (optional):
  chmod +x install_linux.sh
  ./install_linux.sh             (entfernen: ./install_linux.sh --entfernen)


INSTALLER SELBST BAUEN
---------------------------------------------------------------------------
Die Installer entstehen automatisch per GitHub Actions auf je einem
Windows-, Linux- und macOS-Rechner (Datei .github/workflows/build.yml).
Ein Programm wie PyInstaller kann naemlich nur fuer das Betriebssystem
bauen, auf dem es gerade laeuft.

Lokal laesst sich der Installer fuer das eigene System bauen:
  Windows :  build_windows.bat   (benoetigt zusaetzlich Inno Setup 6)
  Linux   :  ./build_linux.sh
  alle    :  python build.py     (build.py --nur-app baut nur dist/)

Details stehen in INSTALLER-ANLEITUNG.txt.


WO WERDEN DIE LERNFORTSCHRITTE GESPEICHERT?
---------------------------------------------------------------------------
In einer SQLite-Datenbank im Benutzerverzeichnis:

  Windows :  %APPDATA%\FISI-Lernplattform\fisi_lernplattform.db
  Linux   :  ~/.local/share/fisi-lernplattform/fisi_lernplattform.db
  macOS   :  ~/Library/Application Support/FISI-Lernplattform/
             fisi_lernplattform.db

Beim Deinstallieren oder Aktualisieren bleibt diese Datei erhalten.
Liegt bereits eine Datei fisi_lernplattform.db neben dem Programm, wird
diese weiterverwendet. Bestehende Lernfortschritte aus einer aelteren
Version gehen also nicht verloren.

Ein anderer Speicherort laesst sich ueber die Umgebungsvariable
FISI_DB_PATH festlegen, etwa fuer ein Netzlaufwerk:

  Linux   :  export FISI_DB_PATH=/mnt/nas/fisi.db
  Windows :  set FISI_DB_PATH=N:\fisi.db

Zum Sichern genuegt es, diese eine Datei zu kopieren.


DATEIEN IM PAKET
---------------------------------------------------------------------------
  start.py              Startprogramm, prueft die Voraussetzungen
  app_gui.py            Oberflaeche: Navigation und alle Ansichten
  fisi_widgets.py       Bausteine des Designs (Karten, Buttons, Diagramme)
  fisi_theme.py         Farbwelt: Palette, Farbverlaeufe, Kategoriefarben
  fisi_core.py          Datenbank, Lerninhalte, Rechner und Suche - ohne
                        Oberflaeche, laesst sich auch allein verwenden
  requirements.txt      Bibliotheken fuer den Start aus dem Quellcode
  requirements-build.txt  zusaetzlich PyInstaller zum Bauen
  build.py              Baut Anwendung und Installer fuers eigene System
  build_windows.bat     Windows-Komfortaufruf fuer build.py
  build_linux.sh        Linux-Komfortaufruf fuer build.py
  FISI-Lernplattform.iss  Inno-Setup-Skript fuer den Windows-Installer
  .github/workflows/build.yml  Baut alle Installer per GitHub Actions
  install_linux.sh      Linux-Startmenue-Eintrag fuer den Quellcode-Start
  LIESMICH.txt          Diese Datei

Die fuenf .py-Programmdateien (start.py, app_gui.py, fisi_widgets.py,
fisi_theme.py, fisi_core.py) muessen im selben Ordner liegen.


EIGENE LERNINHALTE ERGAENZEN
---------------------------------------------------------------------------
Saemtliche Inhalte stehen in fisi_core.py und lassen sich mit einem
Texteditor erweitern. Danach aus dem Quellcode starten bzw. neue Installer
bauen.

Neue Karteikarte (Liste KARTEIKARTEN):

  {"cat": CAT_NET,
   "q": "Deine Frage?",
   "a": "Kurzantwort",
   "a_full": "Ausfuehrliche Musterloesung.",
   "options": ["Kurzantwort", "Falsch 1", "Falsch 2", "Falsch 3"]},

Neue Quizfrage (Funktion build_quiz_database):

  {"cat": CAT_SEC,
   "q": "Deine Frage?",
   "options": ["Richtig", "Falsch 1", "Falsch 2", "Falsch 3"],
   "a": "Richtig",
   "exp": "Erklaerung, warum das richtig ist."},

Als Fachbereich stehen CAT_NET, CAT_SEC, CAT_SYS und CAT_BIZ zur Wahl.
Die Kennzahlen im Dashboard passen sich automatisch an.

Neue AP2-Szenarien sollten als "theme" einen der Themenbloecke aus
AP2_THEMES verwenden. Ein eigenes Thema geht auch - dann in THEME_BLOCK
(ebenfalls fisi_core.py) eintragen, zu welchem Block es im Dashboard
zaehlen soll.

PROBLEMBEHEBUNG
---------------------------------------------------------------------------
Windows zeigt beim Setup "Der Computer wurde durch Windows geschuetzt"
    Der Installer ist nicht kostenpflichtig signiert. Auf "Weitere
    Informationen" und dann "Trotzdem ausfuehren" klicken.

macOS meldet, die App koenne nicht geoeffnet werden
    Die App ist nicht bei Apple beglaubigt. Im Ordner "Programme" mit
    Rechtsklick auf FISI-Lernplattform -> "Oeffnen" -> "Oeffnen". Das ist
    nur beim ersten Start noetig.

"Bibliotheken fehlen" beim Start aus dem Quellcode
    CustomTkinter oder Pillow sind nicht installiert:
      python -m pip install -r requirements.txt

"ModuleNotFoundError: No module named 'tkinter'"
    Tkinter fehlt und muss separat nachinstalliert werden, siehe
    "START AUS DEM QUELLCODE". Die fertigen Installer sind davon nicht
    betroffen.

"'python' wird nicht als Befehl erkannt" (Windows)
    Python wurde ohne das Haekchen "Add python.exe to PATH" installiert.
    Neu installieren und das Haekchen setzen, oder statt "python" den
    Befehl "py" verwenden (py start.py).

"Permission denied" bei ./install_linux.sh, ./build_linux.sh oder der
AppImage-Datei
    Die Datei zuerst ausfuehrbar machen, z.B.:
      chmod +x FISI-Lernplattform-*.AppImage

"Datenbankfehler" beim Start
    Der Speicherort ist schreibgeschuetzt. Ueber FISI_DB_PATH einen
    beschreibbaren Ort festlegen (siehe "WO WERDEN DIE LERNFORTSCHRITTE
    GESPEICHERT?").

Die Oberflaeche wirkt gedraengt
    Das Fenster vergroessern. Empfohlen sind mindestens 1120 x 720 Punkte.
    Bei kleineren Fenstern laesst sich der Inhalt seitlich scrollen
    (Umschalttaste + Mausrad).

Es bleiben Fragen offen oder ein Fehler laesst sich mit dieser Anleitung
nicht loesen: Die vollstaendige Fehlermeldung kopieren, das erleichtert
die weitere Fehlersuche erheblich.
